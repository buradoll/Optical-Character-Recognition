# Optical-Character-Recognition

How to Use
Step1: 
install tesseract-ocr-w64-setup-5.5.0.20241111.exe or go to the link 
https://github.com/UB-Mannheim/tesseract/wiki then download tesseract and install

Step2:
Run: “pip install pytesseract opencv-python pillow numpy matplotlib --target I:\OCR\libs”
Change path us you need

Step3:
Run: python OCR.py

Browse and select your image
